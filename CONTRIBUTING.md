# Contributing to streak

Thank you for your interest in contributing to **streak**! We welcome bug reports, feature requests, documentation improvements, and code contributions.

## 🚀 Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/<your-username>/streak.git
   cd streak
   ```
3. **Create a topic branch** from `main`:
   ```bash
   git checkout -b feature/amazing-feature
   ```

## 📝 Commit Message Guidelines

We follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:

- `feat:` A new feature
- `fix:` A bug fix
- `docs:` Documentation changes only
- `refactor:` Code changes that neither fix a bug nor add a feature
- `perf:` Performance improvements
- `test:` Adding or updating tests
- `chore:` Tooling, CI/CD, or maintenance updates

Example:
```bash
git commit -m "feat: add DirectComposition high refresh-rate smoothing"
```

## 🧪 Testing & Code Quality

Before opening a pull request, ensure:
- All linters, formatters, and typechecks pass without errors.
- Existing tests pass and new unit/integration tests are included where applicable.
- The build succeeds cleanly with zero compiler warnings.

## 📬 Submitting a Pull Request

1. Push your branch to GitHub:
   ```bash
   git push origin feature/amazing-feature
   ```
2. Open a Pull Request against `main`.
3. Provide a clear description of the problem solved and link any related issues.
